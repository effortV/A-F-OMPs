# 致知 ZHIZHI

**NF/RO 膜微污染物截留 —— 知识发现与解释 Agent 系统**

取自"格物致知"：**博闻**（读文献）→ **格物**（找裂缝）→ **量衡**（量真伪）→ **验真**（定证据）。

| 层 | 智能体 | 职责 |
|---|---|---|
| 文献层 | 📚 **博闻 BOWEN** | 读 PDF、建知识图谱、探测矛盾、按需扩检索、带引语取证问答 |
| 模型层 | ⚖️ **量衡 LIANGHENG** | 预测/残差/消融/外推/SHAP/反事实/加描述符重训 |
| 发现层 | 🔬 **格物 GEWU** | **核心**：三引擎自主提出新描述符、知识盲区、跨学科概念 |
| 验证层 | 🧪 **验真 YANZHEN** | 验证调度 + L1 自动跑 / L2 MD 手册 / L3 判别性实验设计 |

数据底座：`dataset.xlsx` 2102 条 × 289 化合物 × 51 膜 × 60 文献；`reference-59/` 59 篇 PDF。
LLM 路由：`Pro/deepseek-ai/DeepSeek-V3.2` 只做文献证据块/元数据预处理；
`deepseek-ai/DeepSeek-V4-Pro` 负责机理主张、知识图谱三元组、候选相关性判断和全部回答；
`BAAI/bge-m3` 负责向量化。关键语义任务不降级到其它模型。

界面是**顶部横向导航**，点左上箭头可折叠成一行摘要。8 个页面，其中模型层排在发现层之前。
Agent 对话通过后台线程池执行：不同 Agent / 不同会话可以并行，切换页面不会中断；
同一会话保持串行，防止消息顺序交叉。

## 模型层：你的模型是一等公民

主模型 = **严格复现既有工作的口径**：12 个子结构（`c` 芳香碳 /6 = 苯环数）在前 +
20 个精炼特征在后 = **32 列**，缺失值交给 XGBoost 原生处理（不插补、不加指示位、
不引入膜身份），`train_test_split(0.2, random_state=108)`。

| | 训练 R² | 测试 R² |
|---|---|---|
| 你报告的 | 0.9974 | 0.8509 |
| **本系统复现** | **0.9975** | **0.8666** |
| 差值 | +0.0001 | +0.0157 |

训练集几乎完全吻合 ⇒ 特征口径与超参一致。测试集那 0.016 来自 `ML-improve.xlsx` 的行级清洗
（该文件未提供）；把它放进 `data/` 可做逐行对齐。模型存成 Booster JSON + sklearn pickle
（`store/models/`），可拿到别处直接用。

围绕它的工具：**预测器**（给 SMILES 自动算 12 个子结构，支持批量 Excel）、
**网格搜索**（grouped / random 两种评分口径）、**学习曲线**（按化合物整簇抽样，
回答"再补多少数据才有用"）、**分层性能拆解**（按膜 / NF-RO / 分子量区间 / 截留区间）、
**原生重要性**（gain / weight / cover）、**误差图**（parity + 残差三联，PNG+SVG）。

诚实诊断（分组 CV、残差考古、外推压测）降级为「外推诊断」子页——它服务发现层，
不是日常预测口径。

## 系统上来就撞出的三条硬事实

**1. 既有模型的 test R²=0.86 被泄漏抬高了 0.38。**

| 口径 | R² |
|---|---|
| 随机切分（既有工作） | **0.858** |
| 留一化合物（新分子） | **0.478** |
| 留一膜（新膜） | **0.219** |
| 留一文献（新课题组） | **0.187** |

数据里同一 (化合物, 膜) 组合最多有 30 条重复记录，随机切分会把近邻样本同时放进
train/test。**发现层只吃分组 OOF 残差**，因为随机切分残差里剩下的是记忆残留而非机理缺失。

**2. 26 个化合物的 SMILES 与报告分子量对不上，波及 406 行（19.3%）。**
Benzylalcohol 的 SMILES 是乙酸，Cyclohexanon 的是氯胺酮，Ibuprofen 的是氯代二苯醚。
这些行的 12 个子结构特征全部错误，其残差不能当机理证据 —— `ml_data_qc` 会在归因前拦下它们。

**3. 289 × 51 的组合矩阵只填了 6.3%（931/14739），106 个化合物只在一张膜上测过。**
引擎 2 据此对 3506 个空白格打分，生成高价值实验清单。

## 首轮运行实测

| 项 | 结果 |
|---|---|
| 核心语料摄取 | 59/59 篇，1231 块，1231 条向量，耗时约 20 分钟（4 线程） |
| 抽出机理主张 | 386 条，全部带 PDF 原文引语与页码 |
| 知识图谱 | 1101 节点 / 1539 边（化合物 371、描述符 239、膜 151…） |
| 文献矛盾 | 6 条，每条带调和变量 + 可证伪预测 |
| Token 消耗 | 输入 1.05 M / 输出 0.17 M（全语料一次跑完） |

矛盾探测抓到的典型对立（这些正是引擎 3 的素材）：

- **ionic strength**：升高离子强度 → 有文献说截留升（孔收缩/堵孔），有文献说降（静电排斥减弱）。
  调和假设：由主导机制决定，取决于膜孔径与溶质分子量之比。
- **silica fouling**：紧膜（NF90/XLE）上污染层提高截留，松膜（NF270）上因 CEOP 降低截留。
  可证伪预测：扫 MWCO 100→500 Da 应存在一个临界值使效应反号。
- **dipole moment**：7 篇里 1 篇说升、4 篇说降。

## 首次描述符闭环实跑：一个被自己的负对照否掉的假设

这是系统上线后跑的第一个完整闭环，结果值得原样贴出来，因为它正是这套机制存在的理由。

**假设**（引擎1 提出）：柔性分子可以侧身穿孔，真实空间位阻不是水相表观 Stokes 半径，
而是构象系综上可达到的最小穿孔截面 `d_min`。

**预注册**（结果产生前锁定，SHA256 `9f98909e…`）：ΔR² ≥ 0.005、bootstrap CI 下界 > 0、
y-scrambling p < 0.05、与既有特征 |r| < 0.9。

**计算**：298/299 个 SMILES 求值成功，范围 0.42–1.56 nm，与 `compound size (nm)` 相关 r=0.825
（低于冗余阈值，约 32% 方差是新的）。

**检验结果**：

| 指标 | 值 | 判定 |
|---|---|---|
| ΔR²（按化合物分组 CV） | **+0.0169** | 看起来达标 ✅ |
| bootstrap 95% CI | **[−0.025, +0.060]** | 跨零 ❌ |
| **y-scrambling 对照 ΔR² 均值** | **+0.0254** | **打乱后比真的还高** ❌ |
| y-scrambling p | 0.70 | ❌ |
| 定向检验（NF & Mw<300, n=901） | 平均 \|残差\| 15.47 → **15.83** | 反而变差 ❌ |

**判定：WEAK，不予采信。** L1 完整电池（10 项检查）又追加了三条独立反证：

| 追加检查 | 结果 |
|---|---|
| 留一文献外推 ΔR² | **−0.0153**（加了反而更差） |
| 外部留出整篇文献（176 行，从未参与训练） | 基线 R²=**−2.31** → 加描述符 **−4.20**，ΔR²=**−1.89** |
| BH-FDR | p=0.70，`survives_bh: false` |

顺带暴露另一件事：**在一篇完全没见过的文献上，模型 R² 是 −2.31 —— 比直接预测均值还差。**
这就是"留一文献 R²=0.187"这个平均数背后的真实分布。

关键在第三行：给 XGBoost 加一列**随机数**，分组 CV 平均也能涨 0.025 R²
（40 特征、`colsample_bytree=0.7` 下的列采样噪声）。真描述符的 +0.017 落在噪声地板以下。
没有 y-scrambling，这就会变成一篇"新型 3D 描述符使 R² 提升 0.017"的论文。

这条负结果被写进卡片和 `val_negative_results`，界定了知识边界：
**在现有 2102 条数据上，单纯的几何最小截面不足以解释残差** —— 
要么需要引入环境依赖（见下面跨界扫描给出的 CCSI），要么需要更多数据。

## 引擎3 跨界扫描实跑

供体领域「药物化学」，产出（完整字段见 UI）：

- **迁移概念**：分子变色龙 —— 分子内氢键动态调节有效极性表面积
- **可计算描述符 CCSI**（截面变色龙指数）：
  `CCSI = (⟨min_cs⟩_water − ⟨min_cs⟩_lowε) / ⟨min_cs⟩_water`，给了 7 步可执行算法，
  引用的全是原语库里真实存在的函数
- **判别性检验**：选一对 MW / 2D-TPSA / logP / 水相平均最小截面都几乎相同、
  但 CCSI 差异大的分子。**H0（尺寸排阻+疏水分配）预测两者截留相同；
  H1 预测高 CCSI 的那个低 >15 个百分点。** 紧膜 (MWCO~200 Da)、1 mM NaCl。
- **自陈风险**：低介电能量近似过简、ETKDG 可能采样不到折叠构象、孔内介电非均匀

注意它没有照抄种子概念（我给的种子是 PSA 版变色龙指数），而是重新表述成"截面收缩"版本 ——
对穿孔物理更贴切。

## 发现层：三引擎 + 描述符闭环

```
引擎1 残差考古     disc_residual_clusters
   分组 OOF 残差 → 特征空间⊕Morgan指纹聚类 → 自由归因
   （随机噪声 / 缺条件变量 / 测量协议差异 / 未建模机理）
   自动标注：该簇是否与 SMILES 错标、缺失模式、单篇文献主导重合

引擎2 图谱覆盖     disc_coverage_map
   value = 0.35·预测不确定度 + 0.25·判别力 + 0.20·外推新颖度
         + 0.15·残差异常度 + 0.05·可行性

引擎3 跨界迁移     disc_propose_domains + disc_crossdomain_scan
   ★ 默认 auto_propose：Agent 自己根据当前残差异常与文献矛盾反推该跨到哪个领域，
     **不限于任何预设池**。优先挑离膜科学远、机制可类比、且有成熟定量描述符的领域。
     实跑它自主提出过：血脑屏障渗透、蛋白-配体识别、土壤吸附地球化学、择形催化。
   另两种模式：rotate（轮转池，用于系统性覆盖）、manual（自由文本指定任意领域）
   必须产出 可证伪预测 + 可计算描述符 + 判别性检验，否则该次扫描判为无效
```

### 描述符生成-检验闭环（顺序不可颠倒）

```
disc_prereg            预注册：结果产生前锁定假设/协议/阈值/证伪条件 → SHA256 存档
disc_compute_descriptor 沙箱执行 compute(smiles)，全 299 个 SMILES 求值
                        与既有特征 |r| > 0.9 → 直接判 REDUNDANT
ml_add_descriptor      ΔR² + bootstrap CI + y-scrambling + 定向亚组 + FDR
lit_novelty_check      查重 → rediscovery 就降级，不许包装成新知识
disc_create_card       出卡 → 验真做 L1/L2/L3 → 人工审卡
```

### 3D 构象原语库 `zhizhi/desc/primitives.py`

现有 20 个特征里**没有任何真 3D 量**（min/max projection 只是 2D 投影），
分子被表示成一个刚性小球。这是描述符语言最大的空白。原语库提供：

| 原语 | 说明 |
|---|---|
| `min_cross_section` | ★ 构象系综 × 64 个取向上的**最小穿孔截面**（含 vdW，Badoiu-Clarkson 最小外接圆）—— 柔性分子可以侧身穿孔，这是 Stokes 半径表达不了的 |
| `chameleonicity` | ★ 变色龙指数：水相(ε=78) vs 孔内低介电(ε=2) 布居下 3D PSA 的相对落差（proxy，须 L2 复核） |
| `intramolecular_hbonds` | ★ 每构象分子内氢键数（几何判据）+ 出现频率 |
| `shape_descriptors` | Rg / NPR1 / NPR2 / 不对称度 / 离心率，均含系综 spread |
| `sasa_profile` | 每构象 总/极性/疏水 SASA |
| `dipole` / `conformer_entropy` / `flexibility` | 偶极、构象熵、柔性 |

沙箱里以 `prim` 注入，Agent 写的 `compute(smiles)` 可直接调用。

## 验证层三级

| 层 | 做什么 | 跑不跑 |
|---|---|---|
| **L1** | 分组CV ΔR² + bootstrap CI、y-scrambling 负对照、语义分组消融、留一文献外推、外部留出文献集、定向亚组检验、混合效应稳健性、BH-FDR 校正 | ✅ 全自动跑 |
| **L2** | MD 方案：**廉价先行路线**（CREST/GFN2-xTB + CPCM 双介电，单分子 CPU 小时级）+ 全 MD 路线（交联聚酰胺膜模型、GAFF2/TIP4P-2005、二维伞形采样 (z, Rg)、量化证伪判据、成本估计、常见坑） | ❌ 只出手册 |
| **L3** | 判别性实验设计：只做能分开 H1/H0 的实验，给预期效应量、功效分析算出的重复数、事先写死的判定规则、对照组、混杂规避、失败模式 | ❌ 只出方案 |

## 三条"防吹牛"机制

1. **预注册**：检验协议在看到结果前 SHA256 存档；无预注册的结果在工单里明确标为"探索性"。
2. **负对照 + FDR**：y-scrambling 和 BH-FDR 是强制项。提 50 个描述符蒙中 2 个"显著"是数学必然。
3. **新颖性查重**：任何自称新知识的卡片先过本地语料 + OpenAlex 查重，查到就降级为 rediscovery。

外加两条工程约束：**无引语不断言**（图谱每条边挂 PDF 原句和页码）、**先排除数据问题再谈机理**。

### 补全文

联网检索经常拿不到闭源全文（Crossref 记录常常连摘要都没有，会直接判 failed）。
博闻页「📤 补全文 / 上传」列出所有缺全文的文献并附 DOI 链接，上传 PDF 后
**原地升级为全文级并重新抽取，不会产生重复记录**。也支持上传全新文献（按 DOI 查重）。
论文身份按规范化 DOI、规范化题名和 PDF SHA-256 三层去重；同一 PDF 改名后也不会重复学习。
博闻页提供重复项扫描/合并入口，合并数据库记录但不会删除磁盘 PDF。

### 知识图谱可视化

- **全局交互图**（plotly）：节点按类型着色、大小按连接数，可按类型/最小度数/节点上限过滤
- **实体邻域图**：搜一个实体画 1-2 跳邻域，边上标关系类型，下方列支撑原文引语
- **矛盾热力图**：描述符 × 膜，蓝=升高截留 / 红=降低截留。**同一行出现蓝红并存 =
  该因素在不同膜上效应反号**，实跑抓到 log Kow、molecular weight、pH、silica fouling 四个
- **静态导出**：PNG + SVG 可直接进论文；GraphML 给 Gephi / Cytoscape

## 性能备注

`DeepSeek-V4-Pro` 是推理模型，一句话问题也会烧近千个思考 token（实测吞吐 52 tok/s）。

| 优化 | 效果 |
|---|---|
| V3.2 先筛证据块，V4-Pro 只审校关键语义 | 降低 V4-Pro 长全文输入费用，同时保留机理/图谱质量 |
| 长文生成关思维链 + `max_tokens` 提到 12000 | L2 方案 **189s → 94s**，且不再被截断、不再混入推敲过程 |
| 对话流式输出 + 默认关思维链 | 首字延迟 **40s → 1.9s**；UI 上有「深度思考」开关按需打开 |
| 客户端超时 180s → 600s | 长文生成不再反复重试假死 |
| 文献摄取 4 线程 + Agent 后台 4 线程 | 文献和多个 Agent 可同时运行，页面互不阻塞 |
| 3D 构象：按柔性+尺寸自适应构象数 + 最小外接圆向量化 | 299 个分子 **数小时 → 1.3 分钟**，数值零偏差 |

界面上会显示每个 Agent 后台任务，以及当前每个文献 worker 正在处理的论文、阶段和进度。
